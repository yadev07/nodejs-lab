# Lab 07: Implementing EventEmitter — Event-Driven Programming

**Lab Number:** 07  
**Date:** 03-10-2026  

## File Summaries
* **events-basic.js**: Demonstrates basic custom event registration, triggering sync flows, and order dependency.
* **order-system.js**: Demonstrates assigning multiple independent listening processes to a single triggered event string.
* **once-vs-on.js**: Showcases the operational difference between persistent listening (.on) versus single-use execution (.once).
* **error-handling.js**: Highlights the structural critical crash behavior of unhandled error events versus graceful capture options.
* **notification-center.js**: Builds a custom domain object extending EventEmitter to handle context-driven communication events.
* **order-tracker.js**: A mini real-time application coordinating staggered delays, lifecycle event states, and continuous uptime configurations.
